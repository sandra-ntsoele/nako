# Nako

Nako is a calm focus timer built with Expo and React Native.

The v0 goal is intentionally small: make a polished timer that can be finished,
demoed, and explained clearly before adding larger iOS platform features.

## Stack

- Expo SDK 57
- React Native
- TypeScript
- Expo Router
- Prettier

## Development

Install dependencies:

```bash
yarn install
```

Start the app:

```bash
yarn start
```

Format the project:

```bash
yarn format
```

Check formatting:

```bash
yarn format:check
```
